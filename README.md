# Praticando Python
Arquivo utilizado para organizar as atividades praticas do curso de pratica da Alura
## Objetivo:
Revisar e reforçar os conhecimentos aprendidos de condicionais através de atividades, explorado o conceito de if, elif, else.
## Atividades:
- acesso_escritório: Avalia se horário de entrada está dentro do expediente e aprova ou nega a entrada;
- calculador_tempo_projeto: Coleta os tempos de cada atividade, faz a validação se não a valores negativos e soma o tempo total se as entradas forem validas;
- calculando_IMC: Realiza calculo de IMC e utiliza condicional para avaliar qual faixa de peso enquadrado;
- controle_orcamento: Verifica se o valor total de despesas informado está dentro do orçamento;
- emprestimo: Avalia se a renda mensal e o valor da parcela se enquadram na politica de aprovação de empréstimo;
- media_estudante: Realiza a soma das notas, calcula a media e informa se o aluno foi aprovado, reprovado ou ficou de recuperação;
- monitor_vendas: Faz a comparação de dois produtos e informa qual deles vendeu mais;
- paridade_numerica: Informa se o número digitado é par ou ímpar;
- pedagio: Campara a distancia percorrida na viagem e informa o valor do pedágio de acordo.
- temperatura_sevidores: Compara a temperatura informada com o limite de temperatura e informa se esta dentro do normal.
